# Online Store API Testing (Fake Store API)

Postman collection and test documents for the Products module of the Fake Store API.

## What's included
- `collection/`: Postman collection (GET, POST, PUT, PATCH, DELETE requests)
- `docs/`: technical design (Products module) and test cases

## What is tested
- Status codes and response schema validation
- Sorting, limit and category filters
- Data-driven requests using collection variables
